개인정보처리방침

종합 자산 관리 · 시행일 2026년 11월 5일

1. 이 사이트

개인이 운영하는 비상업 사이트입니다. 주식·ETF 포트폴리오를 기록하고 보는 도구이며, 운영자가 승인한 구글 계정만 쓸 수 있습니다.

2. 받는 정보와 쓰는 곳

  • 구글 계정 이메일·이름 — 로그인한 사람이 누구인지, 승인된 계정인지 확인하는 데만 씁니다.
  • 승인 명단 — 운영자의 구글 시트에 이메일·이름·쓸 수 있는 기능·승인 요청 기록을 둡니다.
  • 포트폴리오 자료(종목·수량·입출금·메모·화면 설정 등) — 사용자 본인의 구글 드라이브 Index_Data_<이메일> 폴더에 저장합니다. 운영자의 서버에는 저장하지 않습니다.

3. 요청하는 구글 권한

  • openid · email · profile — 로그인한 계정 확인
  • drive.file — 이 사이트가 만든 파일만 만들고 읽고 고칩니다.
  • drive.metadata.readonly — 앱 폴더와 파일을 찾으려고 파일 이름·위치 같은 정보만 읽습니다. 다른 파일의 내용은 읽지 않습니다.

4. 운영자의 접근

로그인하면 이 사이트가 사용자의 앱 폴더(Index_Data_<이메일>)에 운영자 계정의 편집 권한을 줍니다. 운영자는 사용 지원과 자료 복구를 위해 이 폴더를 열어 볼 수 있습니다. 드라이브의 다른 폴더나 파일에는 권한을 주지 않습니다.

5. 밖으로 나가는 정보

  • 시세·지표를 가져올 때 종목 코드만 이 사이트의 서버(Vercel)를 거쳐 Yahoo Finance·네이버 금융·한국투자증권·FRED 등에 보냅니다. 이메일 같은 개인정보는 보내지 않습니다.
  • 학습자료(HTML) 올리기 기능으로 올린 파일은 링크를 아는 사람이 볼 수 있게 공유됩니다.
  • 받은 정보를 광고에 쓰거나 팔거나 다른 곳에 넘기지 않습니다.
  • 구글 API로 받은 정보의 사용·전달은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다.

6. 브라우저에 남는 것

로그인 이메일과 비밀번호(PIN) 확인값은 탭을 닫으면 지워지는 세션 저장소에 둡니다. 증시 휴장일 달력은 브라우저에 7일 동안 보관합니다.
