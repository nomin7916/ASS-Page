# 맥미니 원격 — 빨리 닿는 순서 (2026-11-26)

사용자 지침: 맥미니는 늘 켜 둔다 · 검색·크롬 연동 작업은 맥미니가 한다 · 사용자 할 일은 최소로, 필요하면 링크와 짧은 사용법만.

## 0. 먼저 알 것 (2026-11-26 확인)
- 클라우드 세션·클라우드 예약 작업에는 크롬이 없다.
- 이 클라우드 세션은 코워크 환경에 예약 작업(create_trigger)도 새 대화(create_session)도 **만들 수 없다** — 둘 다 거절됨. 다시 시도하지 말 것.
- 맥미니에 닿는 길은 둘뿐이다: (A) Remote Control 폴더로 이 세션에 붙이기 (B) 맥미니의 Claude 데스크톱 앱 대화가 직접 하기.

## 1. 바로 해 볼 것 (사용자에게 묻기 전에)
1. `list_computer_folders` — 맥미니 폴더가 있고 online 이면 `request_computer_folder`(사용자는 승인 창만 누른다).
2. 붙으면 맥미니에서 할 일(크롬·Bash·예약 작업 만들기)을 바로 한다.
3. 목록이 비었으면 2로.

## 2. 사용자에게 줄 안내 — 둘 중 쉬운 것 하나
⚠️ 단계를 건너뛰지 않는다(사용자 지침 2026-11-26: "네가 보는 화면과 내가 보는 화면이 다를 수 있잖아"). 화면을 여는 법부터
번호를 매겨, 누를 것의 자리·이웃 항목·색까지 적는다. 이미 열려 있다고 가정하지 않는다.

**(A) 폴더 연결 — 한 번 해 두면 다음부터 안 물음 (권함 · 2026-11-26 실제로 드린 안내)**
1. 키보드에서 ⌘(커맨드) + ,(쉼표) → 설정 창.
2. 왼쪽 목록 **Code** → 오른쪽을 아래로 내려 **폴더 (n개)** 줄의 **폴더 추가** 단추.
3. 새 창 왼쪽 "위치" 아래 **aruimacmini**(집 모양) → 가운데 목록에서 **응용 프로그램** 바로 아래 · **flutter** 바로 위 줄 **Developer** 를 한 번 누름.
4. 오른쪽 아래 파란 **폴더 추가** → 저에게 "됐어".
(홈 폴더 자체·숨김 폴더·~/Library 안 폴더는 클라우드에 내주지 않는다 — 2026-11-26 "ASS-Page" 폴더가 그래서 안 됨.)
같은 화면의 "Remote Control 사용을 위해 이 컴퓨터를 절전 모드로 전환하지 않음"도 켜 달라고 한다.

**(B) 붙여 넣기 한 번 ((A)가 안 될 때)**
> 맥미니 Claude 앱 왼쪽 위 **＋ 새로 만들기**(또는 ⌘N)로 새 채팅을 열고 아래 한 줄을 붙여 넣어 주세요. 이 대화는 그대로 남습니다.
> 그 한 줄에는 할 일 전체를 담는다(그 채팅은 저장소를 못 볼 수 있다 — 저장소 파일이면 "맥미니 크롬으로 https://github.com/nomin7916/… 를 열어 읽고" 라고 적는다).

## 3. 지킬 것
- 위장 헤더(브라우저 흉내 UA·Referer)로 막힘을 피하지 않는다. 사람이 보는 공개 화면을 사용자 브라우저로 읽는 것만.
- 비밀번호·카드 번호를 넣지 않는다(로그인 창이면 사용자에게 링크).
- 자산관리 사이트(ASS-Page) **앱 화면**을 맥미니에서 새로 열면 다른 기기 로그인이 끊긴다(useDriveSync 세션 파일) — 꼭 필요할 때 한 번만. `/api/...` 주소는 괜찮다.
- 열쇠·토큰은 답·파일·커밋에 적지 않는다.
